# ZENOBIA

Русскоязычная интерактивная история Зенобии: **ровно десять глав**, географическая карта 267–272 годов, локальная 3D-реконструкция Пальмиры, монета и режим школьного выступления.

## Запуск

Node.js 22+, npm 10. Зависимости зафиксированы в `package-lock.json`.

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000. Для готовой статической версии:

```bash
npm run build
npm start
```

`npm start` раздаёт **out/**, не исходники. Другой порт: `PORT=3100 npm start`. Нельзя открывать `out/index.html` через `file://`: для модулей и моделей нужен HTTP. После установки и сборки внешний интернет для показа не требуется; шрифты, фото, география, GLB и декодер Meshopt локальны. Ссылки на источники требуют интернета. Service worker не используется.

## Управление

- **Главы** — прямой переход; **Исследовать** — город; **Источники** — библиография и лицензии.
- **Презентация** — текущая глава на весь экран; отказ Fullscreen API не мешает работе в окне.
- В презентации: `←`/`→`, `Пробел`, `Home`/`End`; `N` — заметки, `F` — полный экран, `Esc` — выход. Клавиши не перехватываются в формах и интерактивных кнопках.
- Город: **Исследовать 3D**, перетаскивание — орбита, колесо — масштаб; сброс камеры, условные руины и доступные текстовые точки интереса.
- Монета: обе стороны, остановка вращения, расшифровка легенд. **Без 3D** оставляет локальные фотографии.
- Карта: ползунок/кнопки лет, воспроизведение, города и регионы; сброс вида.
- Родословная, версии судьбы Зенобии, галерея и необязательный тест работают без внешних API.

## Выступление на 7–10 минут

Заметки находятся в `src/data/chapters.ts` и доступны клавишей `N`. Это **не отдельный приватный экран докладчика**: панель видна на проекторе, закрывайте её перед объяснением иллюстрации. Рекомендуемый темп: пролог 30 сек.; кризис 45; Пальмира 60; восхождение 55; экспансия 60; Augusta 55; Аврелиан 55; падение 60; наследие 50; эпилог 30. Добавьте паузы на карту и монету. Для 1366×768 и шире в горизонтальной ориентации предусмотрена компактная раскладка; на телефоне слайды допускают вертикальную прокрутку.

## 3D и историческая достоверность

**Внешняя модель:** храм Бела — Giovanni De Gasperis и A. Cordisco / #NEWPALMYRA, CC BY 4.0. OBJ конвертирован в GLB, объединён в один mesh, добавлены проекционные UV, каменные материалы, квантование и Meshopt. 150 550 треугольников, 2 321 628 байт. Подробности и ссылки — `ASSET_CREDITS.md`.

**Создано здесь:** колоннада с каннелюрами и условными капителями, арка, схематичный театр, рельеф, фоновые камни, пыль, освещение и объём монеты. Фототекстуры монеты внешние. Город — художественная композиция, **не научная реконструкция точного плана**. Переключатель руин меняет колоннаду и арку, а не воспроизводит конкретную дату разрушений; храм остаётся в реконструированном виде. Фото галереи снято в 2010 году, а не показывает нынешнее состояние памятника.

Внешние модели не скачиваются во время показа. Поиск рассмотрел Sketchfab, #NEWPALMYRA и GitHub; выбран проверяемый открытый OBJ, не извлечённый из закрытого просмотрщика. При отсутствии WebGL2/ошибке загрузки сохраняются изображения и текст. Вне видимой области canvas размонтируется; reduced motion отключает автоматическое движение и декоративные анимации. Это не гарантия 60 FPS на любом устройстве.

## Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Проверка именно production-export (при запущенном `PORT=3100 npm start`):

```bash
TEST_URL=http://localhost:3100 npm run test:e2e
```

E2E: десять глав, карта, навигация, заметки, границы, отказ fullscreen, клавиатура ползунка, внешняя модель, монета, галерея, тест, WebGL fallback, reduced motion, консоль и отсутствие горизонтального переполнения на 1920×1080, 1440×900, 1366×768, 768×1024, 390×844. Проверка выполнена в Chromium/Linux, не заменяет тест Safari/iOS или физического проектора.

## Бесплатное размещение

Готовый `out/` можно разместить на статическом хостинге. Для Vercel: импортировать репозиторий, preset Next.js, install `npm ci`, build `npm run build`; `vercel.json` задаёт заголовки безопасности. Либо загрузить `out/` на Cloudflare Pages (build `npm run build`, output `out`). Аккаунт и публикация требуют разрешения владельца — **публичный деплой не выполнен**. На другом хостинге перенесите заголовки из `vercel.json` в его конфигурацию. Вариант GitHub Pages с подпапкой потребует отдельной настройки base path и путей ресурсов; сейчас рассчитано на корень домена.

Нет сервера приложений, форм сбора данных, аккаунтов, аналитики или платных API. CSP допускает inline-скрипты экспорта Next и WebAssembly декодера, но не внешние origin. Локальный сервер предназначен для показа, не для публичного production-хостинга.

## Структура и воспроизведение ресурсов

- `src/data/chapters.ts`, `sources.ts` — текст, заметки и источники.
- `src/components/` — оболочка, карта, взаимодействия, fallback.
- `src/three/` — город, внешний храм, материалы, монета.
- `public/images/`, `models/`, `textures/` — локальные ресурсы.
- `scripts/prepare-assets.mjs` — оптимизация сохранённых оригиналов и обновление Natural Earth (нужен интернет для географии).
- `scripts/stone-textures.mjs` — собственные каменные текстуры.
- `scripts/convert-temple.mjs /path/to/PalmyraTemple.obj` — воспроизводимое преобразование модели; исходный OBJ находится в `public/models/temple-bel-source.zip`.
- `TASKS.md`, `PROGRESS.md`, `docs/` — состояние, решения и ограничения.

Не запускайте обновление ресурсов для обычной сборки: все готовые файлы уже включены. Лицензии сторонних материалов не заменяются лицензией кода. Известное исключение аудита инструментов разработки описано в `docs/SECURITY.md`.
