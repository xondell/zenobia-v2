## Переходы и монета
Переходы в режиме презентации: Web Animations API, 220 мс завершение + 420 мс появление, направление по движению вперёд/назад. Кнопки, меню и клавиатура используют один `go()`. Ref-блокировка предотвращает гонки при серии команд, выход отменяет активную анимацию. Reduced motion — мгновенная смена. В режиме чтения — плавная прокрутка; GSAP управляет только вложенными scroll-reveal, не анимирует те же элементы, что WAAPI.

Легенды — настоящие доступные кнопки: `S ZЄNOBIA AVG` (нормализованная запись S ZENOBIA AVG) → аверс, `IVNO REGINA` → реверс. R3F плавно меняет rotation.y реального mesh; фототекстуры и UV сохранены. Камера/OrbitControls сбрасываются к фронту. Автовращение выключается до явного возобновления, ручное управление остаётся. При выключенном WebGL доступен фотографический резерв.

## Ревью и исправления
Независимое read-only ревью не нашло Critical, но воспроизвело конфликт глобального Esc при нескольких открытых картах и пересечение нижних блоков монеты. Добавлены регрессионные тесты, оба дефекта воспроизведены до исправления. Esc теперь относится к карте с текущим фокусом; нижняя информация сцены размещена единым flex-потоком вместо независимых фиксированных позиций. Фотографический резерв монеты совпадает с областью Canvas, исключая видимую вторую монету позади него. Проверка 390×844 дополнительно выявила отсутствие имён у иконок мобильной навигации: добавлены aria-label без изменения внешнего вида.
